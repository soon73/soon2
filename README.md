# 뿌리영어 (soon2)

어원으로 익히는 영어 단어 앱 (초보자용). 1,812단어를 5개 레벨로 나누고, 같은 어근 단어를 한 번에 익히도록 구성했습니다.

## 사용법
- `index.html` 하나로 동작합니다. 브라우저(크롬/사파리)에서 열면 됩니다. GitHub Pages로 올려도 됩니다.
- 마이크 발음 교정은 마이크 권한이 허용된 브라우저에서만 동작합니다.
- 학습 기록은 브라우저 localStorage에 저장됩니다.

## 기능
- 하루 10단어 학습 → 퀴즈 → 맞힌 단어 자동 체크
- 어근 가족 나무, 접두사/어근/접미사 색 블록, 연상 문장
- 레벨 5단계 (입문·초급·중급·중상급·상급), 식물 성장 진도, 1,812칸 단어 지도, 달력, 배지
- 간격 반복 복습 (1·3·7·14·30일)
- 발음 교정: 원어민 TTS, 음성 인식 점수, 글자별 비교, 내 목소리 재생, 한국인 약점 발음 팁

## 데이터 수정 / 빌드
- `data/l*.txt`: 단어 데이터. 형식은 다음과 같습니다.
  - `@N` 레벨 시작
  - `#어근|뜻|기원|이모지|연상 문장` 어근 그룹
  - `단어|뜻|분해|어원 풀이(선택)` 단어
- `template.html`: 앱 화면과 코드. `python3 build.py`를 실행하면 `index.html`이 만들어집니다.
